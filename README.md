# Métodos Numéricos

Proyecto de práctica para resolver ecuaciones de una variable usando métodos numéricos con una interfaz gráfica en Python.

## Descripción

Este programa incluye una aplicación con Tkinter para calcular raíces de funciones mediante:

- Bisección
- Newton-Raphson
- Steffensen

## Requisitos

- Python 3.10 o superior
- Bibliotecas:
  - tkinter
  - sympy

## Instalación

1. Clona este repositorio.
2. Entra a la carpeta del proyecto.
3. Instala las dependencias necesarias:

```bash
pip install sympy
```

## Ejecución

```bash
python metodos_numericos.py
```

## Ejemplo de uso

Se puede resolver ecuaciones como:

- `x**3 - x - 2`
- `x**2 - 2`

- `metodos_numericos.py` — lógica principal y interfaz gráfica.
